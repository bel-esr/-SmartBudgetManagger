# -SmartBudgetManagger
README : SmartBudget Manager

1. About the Workbook :
SmartBudget Manager is an Excel workbook designed to help users manage their monthly finances. It allows users to record income and expenses, organize spending by category, calculate the monthly balance, and view financial information through a dashboard and charts.
2. Requirements :
Microsoft Excel 2016, 2019, 2021, Microsoft 365, or a compatible spreadsheet application.
Basic computer skills.
The SmartBudget Manager Excel file.
3. Main Features:
Record monthly income and expenses.
Organize expenses into predefined categories.
Calculate total income, total expenses, and monthly balance.
View financial summaries and charts on the Dashboard.
Identify budget overruns through visual warnings, if configured in the workbook.
4. Getting Started :
1.Open the SmartBudget Manager Excel file.
2.Go to the Transactions worksheet.
3.Enter the date, description, transaction type, category, and amount in the appropriate columns.
4.Open the Dashboard worksheet to review your financial summary.
5.Save the workbook after making changes.
5. Important Notes :
Enter data carefully and avoid modifying existing formulas. Check the workbook's categories and budget values before using it. Keep a backup copy of your file to prevent data loss.
